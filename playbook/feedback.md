# User feedback on posted visuals (newest at the bottom). Read this before designing any post and apply every item to all future posts.
- The loss red is #E23B3B ("True Economy red"), not orange-ish.
- Facebook crops the top and bottom of vertical video: keep the title headroom (b1=137) and the source line at H-57.
- First frame must equal the final frame; only the chart animation moves, never the title, footer or source.
- (2026-11-06, trade deficit post) CLARITY FIRST (replaces the earlier colour wording; see brand.md 'Clarity first'): COLOUR LOGIC MATCHES MEANING: things of the same kind get the same colour (bought and sold are BOTH blue); only the difference/gap/problem is True Economy red. Never give related bars different shades for variety. RELATIONSHIPS ON ONE CHART: a derived figure (gap, net, share) is drawn on the same scale, aligned under/over its source and joined by thin dotted guide lines; unconnected separate sections look unrelated. BREAKDOWNS ARE A VISIBLE SUM: number the steps (1. 2. 3.), write the arithmetic in the last label (e.g. "$1,260bn − $328bn = the trade deficit"); a positive item that reduces a red total is green with a short note like "cuts the gap". LABELS FOR A FIRST-TIME VIEWER: plain words with the number in the sentence ("US buys $1,260bn more than it sells"). NO COLLISIONS: check every label against every dotted line and bar in the render; shorten or move the label so it ends before the line. FINAL TEST: could a confused viewer explain each section back in one sentence? If not, simplify or relabel.
- (2026-11-06) INSTAGRAM allows a MAXIMUM of 5 hashtags per post (caption plus first comment combined). Use at most 5 on Instagram, ideally 3-5 of the most relevant; never 6-8.
